# 1과목 회고 (이름)

## 내가 만든 것
- 보안 경보를 LLM으로 분석하고 위험도별로 정렬하여 보고서를 생성한 뒤, 알림 서버로 전송하는 파이프라인을 만들었다.

## 가장 어려웠던 것
- `make_line()` 함수와 `lines` 변수의 차이를 이해하는 것이 어려웠다.
- 처음에는 줄바꿈 개수를 확인할 때 `make_line(lines).count("\n")`이라고 작성했다. 
    하지만 `make_line()`은 딕셔너리 한 건을 문자열로 바꾸는 함수이고, 
    `lines`는 반복문을 통해 완성된 문자열을 저장한 변수라는 것을 알게 되었다.
- 이미 결과가 변수에 저장되어 있다면 
    함수를 다시 호출할 필요 없이 `lines.count("\n")`으로 검사하면 된다는 것을 이해했다.

## 리뷰에서 찾은 것과 고친 것
- 6-3 문제에서 딕셔너리의 severity를 sevrity로 잘못 작성해 KeyError가 발생하는 것을 확인했다. 
    딕셔너리에 존재하는 키 이름과 코드에서 사용하는 키 이름이 정확히 일치해야 한다는 것을 배웠다.

- 6-5 문제에서는 위험도 값에 대문자나 공백이 섞여 있어 high 경보를 제대로 세지 못했다. 
    .strip().lower()를 사용해 공백과 대소문자를 통일하면서 오류를 수정했다.

- 또한 assert를 사용해 수정한 코드가 예상한 결과를 반환하는지 검사하는 방법을 익혔다.

## 캡스톤에서 더 해 보고 싶은 것
- 아직 하나의 완성된 결과물이 어떤 모습인지 잘 모르겠다. 
    문제를 하나씩 풀면서 개별적인 코드와 기능은 조금씩 이해하고 있지만, 
    이것들이 서로 어떻게 연결되고 어떤 역할을 하는지 전체적인 흐름을 파악하는 것은 아직 어렵다.

캡스톤에서는 단순히 주어진 문제를 해결하는 것에서 나아가, 
지금까지 배운 기능들이 어떻게 연결되어 하나의 프로그램으로 완성되는지 이해해 보고 싶다.
