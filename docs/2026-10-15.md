# 2026-10-15 아침 과제 11 — VS Code 커스터마이즈

## 1. 학습 목표
- VS Code 작업 환경을 개인에게 맞게 설정한다.
- 확장 프로그램의 역할을 이해한다.
- AI 코드 자동 완성과 IntelliSense를 구분한다.

## 2. 실습 내용 및 결과
| 항목 | 결과 |
|---|---|
| 테마 | Light 선택 |
| 언어 | 영어 유지, 한국어팩 설치 생략 |
| 터미널 | 13인치 노트북에 맞춰 아래쪽 유지 |
| Error Lens | 설치 및 오류 표시 확인 |

| GitHub Copilot | 확장 미설치 확인 |
| Inline Suggest | 이미 비활성화되어 있음 확인 |

## 3. 오류 확인 및 수정
```python
def hello():
    name = "kim"
    print(name
```
- Error Lens에서 `"(" was not closed` 메시지를 확인했다.
- 마지막 줄에 `)`를 추가하자 오류 메시지가 사라졌다.
- 오류 표시 기능과 실제 코드 수정은 별개라는 것을 이해했다.

## 4. 새로 알게 된 것
- Extension은 VS Code에 필요한 기능을 추가한다.
- indent-rainbow는 들여쓰기 깊이에 따라 색상을 구분한다.
- IntelliSense는 함수·속성 탐색 및 오타 방지에 도움이 된다.
- 터미널 위치와 테마는 코드 실행 결과를 바꾸지 않는다.
- `@installed`는 설치된 확장 프로그램을 검색하는 필터다.

## 5. 내가 직접 판단한 일
- 영어 인터페이스를 유지하기 위해 한국어팩을 설치하지 않았다.
- 13인치 노트북에서는 터미널을 아래쪽에 두는 것이 더 편하다고 판단했다.
- Light 테마를 선택했다.

## 6. 추가 확인
- 다른 AI 자동 완성 확장의 활성화 여부는 별도로 전수 확인하지 않았다.
