# 2026-10-16 (금)

## 찾아본 것
서버에서 설정 파일을 고치는 방법:
서버에 SSH로 원격 접속하면 터미널에서 명령어를 실행할 수 있다. 서버에 VS Code가 없어도 vim과 같은 텍스트 편집기를 이용하면 그래픽 인터페이스 없이 키보드만으로 설정 파일을 열고 수정할 수 있다.

## 오늘 새로 쓴 명령
vim

## vim 으로 한 것
입력 모드로 들어가는 키: i <br>
일반 모드로 돌아오는 키: ESC <br>
저장하고 나가는 명령: :wq <br>
저장 없이 나가는 명령: :w<br>
지운 것을 되돌리는 키: U <br>

## 막힌 것
vim 을 실행하기 위해 처음에 'vim'을 붙여야 하는 것을<br> 깜박하고 입력한다.

## 다음에 확인할 것
VS Code와 같은 개발 도구 없이 터미널 환경에서 직접 파일을 작성하고 프로그램을 실행하는 전체 과정이 궁금하다. 특히 실제 리눅스 서버에 SSH로 접속한 뒤 `vim`으로 코드를 작성하고 실행하는 과정을 실습해 보고 싶다.
