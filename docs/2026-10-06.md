## 찾아보고 알게 된 것

API 키는  
API를 사용할 때 요청을 보낸 사용자를 확인하기 위한 비밀 인증키이다.

무료 등급은  
돈을 내지 않고 사용할 수 있지만 호출 횟수나 사용량 등에 제한이 있는 이용 방식이다.

보안 담당자가 다루는 서버는  
Linux 기반 서버를 많이 다루기 때문에 Bash 명령어를 익혀두면 도움이 된다.

깃배시를 쓰면  
Windows에서도 Bash 명령어를 사용할 수 있어서 Linux 서버와 비슷한 방식으로 명령어를 연습할 수 있다.

## 키가 틀렸을 때와 키가 없을 때의 차이

키가 틀렸을 때는 `401` 오류와 `UNAUTHENTICATED` 메시지가 나왔다.  
키를 아예 보내지 않았을 때는 `403` 오류가 나왔고, API Key 같은 인증 정보가 필요하다는 메시지가 나왔다.

즉, 틀린 키를 보낸 경우와 인증 정보를 아예 보내지 않은 경우는 서버에서 서로 다르게 처리된다.

## 막힌 것

처음에는 터미널 명령어 앞의 `$` 기호까지 입력해서 `command not found` 오류가 났다.  
또 틀린 API 키로 계속 요청해서 `401` 오류가 나오기도 했다.  
정상 API 키를 다시 넣은 뒤에는 모델 목록이 정상적으로 출력되었다.
