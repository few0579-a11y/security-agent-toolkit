# 2026-10-08 (목)

## 오늘 새로 쓴 명령
- `git config` : Git에 사용자 이름과 이메일을 설정한다.
- `git add` : 다음 커밋에 포함할 파일을 선택한다.
- `git commit` : 선택한 파일의 변경 사항을 기록한다.
- `git push` : PC에 저장한 커밋을 GitHub 원격 저장소로 전송한다.

## 찾아보고 알게 된 것

**add와 commit과 push는**

파일을 바로 GitHub에 올리는 것이 아니라, 올릴 파일을 선택하고 변경 내용을 기록한 다음 원격 저장소로 전송하는 세 단계로 나뉜다. 이렇게 하면 어떤 파일을 기록하고 공유할지 직접 관리할 수 있다.

**untracked · tracked · staged는**

- untracked : Git이 아직 추적하지 않는 새 파일
- tracked : Git이 이미 관리하고 있는 파일
- staged : `git add`로 다음 커밋에 포함하도록 선택한 상태

## 막힌 것

1. `git config`를 `git congig`로 잘못 입력해 오류가 발생했다. 철자를 수정하여 해결했다.
2. `git status`에서 빨간색으로 표시된 파일들을 처음에는 오류라고 생각했지만, 아직 커밋하지 않은 변경 사항이라는 것을 알게 됐다.
3. `git push` 실행 시 GitHub 인증 화면이 나타났고, 브라우저에서 로그인 및 권한 승인을 진행해 업로드에 성공했다.
