# 2026-10-07 (수)

## 오늘 새로 쓴 명령
- `git init` : Git 저장소 초기화
- `git remote add` : 원격 저장소 등록
- `git fetch` : GitHub 기록 가져오기
- `git reset` : 로컬 브랜치 기록 위치 맞추기
- `git branch -u` : 원격 브랜치 추적 설정
- `git status` : 현재 Git 상태 확인

## 찾아보고 알게 된 것
- **Git**은 파일의 변경 이력을 관리하는 도구다.
- **저장소(repository)**는 프로젝트 파일과 변경 기록을 관리하는 곳이다.
- **원격 저장소(remote)**는 GitHub처럼 다른 위치에 있는 Git 저장소다.
- Git을 이용하면 파일을 웹에서 하나씩 업로드하지 않고 변경 사항을 기록하고 공유할 수 있다.

## 막힌 것
1. `.gitignore` 파일 이름을 `.gitipnore`로 잘못 작성했다.
   - 파일 이름을 수정하여 해결했다.
2. `git status` 출력 결과를 터미널에 붙여 넣어 Bash 오류가 발생했다.
   - 출력 결과는 실행 명령어가 아니라 상태를 알려주는 메시지라는 것을 알게 됐다.
3. `git branch -vv`에서 `[origin/main]`이 표시되지 않았다.
   - `git branch -u origin/main`으로 원격 브랜치를 연결했다.

- 수정한 파일을 GitHub에 올리는 방법
