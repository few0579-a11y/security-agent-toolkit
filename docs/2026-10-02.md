- VS Code 터미널은 PowerShell이나 Git Bash 등 원하는 환경을 선택할 수 있다.
- MINGW64가 보이면 Git Bash를 사용 중이라는 뜻이다.
- requests는 Python 코드에서 인터넷 요청을 보낼 때 사용한다.
- curl은 터미널에서 인터넷 요청을 보낼 때 사용하는 명령어다.
- Jupyter 노트북은 Kernel을 선택해야 코드를 실행할 수 있다.
